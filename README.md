# Escola de Xadrez

Jogue xadrez contra o Stockfish com um treinador que comenta cada lance, 470 puzzles táticos com repetição espaçada, treinos e aulas. Site estático: abra `index.html` em qualquer servidor.

O Stockfish (`stockfish.js`) e o chess.js (dentro de `engine.js`) são software livre, sob as licenças GPL e BSD respectivamente.
